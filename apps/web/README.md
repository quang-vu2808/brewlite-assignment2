# BrewLite Web

Next.js menu UI for Sprint 1. It reads the live product list from the NestJS API and presents loading, empty, error, and retry states. See the repository [README](../../README.md) for setup, `.env` configuration, team workflow, and the complete local commands.

Run from this directory after starting the API:

```powershell
npm ci
npm run dev
```

Validation commands:

```powershell
npm run lint
npm test -- --run
npm run build
```
